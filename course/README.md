# Course

Challenges from my university course, one write-up per challenge, plus the
technique each one taught.

The write-ups here document the **method**, never the answer. Flags are
redacted: the challenges live on the course's private platform, and publishing
solutions would break the course rules and spoil the exercise for classmates.
What is public is how to think through a challenge of that kind — which is the
part worth keeping anyway.

## Layout

Challenges are filed generically for now. Once a challenge's class is known it
moves to `course/class-NN-topic/`. Each write-up links to the reusable note for
its technique in [`notes/`](../notes/README.md), so the theory is written once
and reused across challenges.
